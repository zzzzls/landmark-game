# 北京地标盲猜

亮色像素北京街机：每人贡献两个地点，在真实无文字地图上盲猜三个位置。提交立即看个人成绩，全场结束按总距离误差排名。

## 启动

需要 Node.js、npm、Python 3.11+ 和 uv。浏览器验收使用本机 Google Chrome。

```sh
npm ci
uv sync
# 首次使用才复制，已有 .env 不要覆盖
cp .env.example .env
# 填写高德配置后启动
npm run dev:all
```

默认前端 `5173`、后端 `8000`，均绑定所有网卡。Vite 代理 API 和 WebSocket，只需向朋友分享前端地址。手机与本机网络需互通；管理员页面提供局域网邀请链接。终端按 `Ctrl+C` 停止该次启动的前后端。

- 玩家：`http://localhost:5173/`，首次填写昵称后自动进入当前房间，无需房间号。
- 管理员：`http://localhost:5173/admin`，创建房间、开始、提前揭晓和重开，也可参加答题。
- 大屏：`http://localhost:5173/screen`，自动跟随当前房间。

手机使用 `http://本机局域网IP:5173/`，不要使用手机自己的 `localhost`。无房间时玩家和大屏等待，管理员建房后自动进入。知道 `/admin` 地址的人即可管理，这不是登录鉴权系统。

`.env` 中 `AMAP_JS_KEY`、`AMAP_JS_SECRET` 为地图必需配置；可选 `AMAP_WEB_KEY` 提供地点搜索，缺少或调用失败时回退内置北京目录。配置需要允许实际访问的本机及局域网地址。地图需要外网；失败页面可重试。不要提交密钥或保存带凭据 URL 的网络日志。

端口冲突时：

```sh
FRONTEND_PORT=5175 BACKEND_PORT=8002 npm run dev:all
```

## 游戏与换局

1. 全站只有一个当前房间。每人贡献两处地点才就绪，至少一人就绪才能开局；未就绪和中途加入者旁观本局。
2. 每人三题，至少一道系统题，不含本人贡献、无重复；单人三道均来自系统。
3. 地图固定标注天安门 🚩、鸟巢 🏟️、北京西站 🚉、国贸 🏙️，帮助辨认方向。这些地点及其 50 米范围内的点不参与抽题，也不能作为贡献地点。
4. 点击地图预览，再确认保存；提交前三题可修改、撤销，全部确认后提交并锁定。
5. 提交者立即看到自己的总误差、逐题成绩、真点与连线；其他人继续答题，收不到这些私人结果。
6. 全员提交自动揭晓，也可由管理员提前揭晓。误差逐题取整到米后求和，升序排名；未提交者不计分、不排名。
7. 管理员在揭晓后点击“重开一局”，创建后继房间。玩家和大屏自动切换，保留昵称、重新出题。普通玩家等待，无需刷新。

大屏结算逐人列出三题名称与误差，每页六人、十秒轮播，支持暂停及手动翻页；地图跟随当前页。像素动效短暂播放、不阻塞操作，并尊重减少动态效果设置。

旧 `/r/CODE` 系列链接按角色转到当前固定入口。房间和成绩保存在单进程内存中，服务重启后消失，页面回到等待建房。不要使用多 worker。相同昵称、相同角色用于刷新恢复，也会接管旧连接；旧页面会提示更换昵称。

## 验证

```sh
npm run build
npm run test:rules
npm run test:unit
# 在独立端口启动全新的 dev:all，保证尚未建房，再运行：
PLAYTEST_BASE_URL=http://localhost:5175 npm run test:e2e
# 自动占用独立的 5176/18004，测试真实进程重启并自行关闭
npm run test:recovery
```

30 人协议并发测试必须使用另外一个全新的测试后端，不能对正在游玩的房间执行：

```sh
# 终端一：独立测试后端
uv run uvicorn backend.main:app --host 0.0.0.0 --port 18003
# 终端二：初始必须无房间；用局域网 IP 可验证该地址可达
uv run python tests/load_session.py --url ws://127.0.0.1:18003 --players 30
```

测试与限制见 `PLAYTEST.md`。有效入口是 `src/` 和 `backend/`；`server/` 为历史实现。

## 项目设计技能与静态资源

前端设计从 [.agents/skills/landmark-ui-design/SKILL.md](.agents/skills/landmark-ui-design/SKILL.md) 开始，按任务选择已安装的 BeUI、Transitions、shadcn 与 taste-skill，并参考 Beautiful UI、Rare UI 的项目适配指南。技能随仓库提交；版本、许可与本地适配见技能中的来源记录。保留像素北京街机风格，不自动改换视觉体系。

允许按需采用 Tailwind，通过 npm 和 Vite 本地构建；不使用浏览器 CDN。实际使用的字体、图片、图标、脚本、样式及其嵌套资源必须保存到项目并同源提供。运行时仅高德地图所需服务允许联网；开发时仍可查阅资料与下载依赖。项目字体和像素图形已在本地，地图需要外网。

`npm run test:resources` 检查三个角色的冷启动、等待页和真实地图大厅，禁止非高德的外部资源请求。必须使用独立且初始无房间的后端，启动生产构建预览的方法见 `PLAYTEST.md`。它不代替完整游戏流程测试。
