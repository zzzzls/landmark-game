# 北京地标盲猜

在没有文字标注的北京地图上，和朋友比一比方向感。每人贡献两个地点，再盲猜三个位置，总距离误差越小排名越高。

## 启动

需要 Node.js、npm、Python 3.11+ 和 uv。本地安装 Google Chrome 可运行浏览器验收。

```sh
npm ci
uv sync
cp .env.example .env  # 已有配置时不要覆盖
# 在 .env 填写高德配置
npm run dev:all
```

打开 http://localhost:5173 。前端与后端默认绑定所有网卡，手机可通过房主页面的局域网邀请链接加入，需网络可互通。后端端口 8000，由 Vite 代理 API 和 WebSocket；只需分享前端地址。

`.env` 配置：

- `AMAP_JS_KEY`、`AMAP_JS_SECRET`：高德浏览器地图所需。
- `AMAP_WEB_KEY`：可选，提供高德地点搜索；未配置或搜索服务失败时回退内置北京目录。

不要提交密钥。高德配置需要允许实际使用的本机或局域网地址。地图依赖外网，地图错误页支持重试。

端口冲突可使用 `FRONTEND_PORT=5174 BACKEND_PORT=8001 npm run dev:all`。运行测试时使用相同 `PLAYTEST_BASE_URL=http://localhost:5174`。不要停止来源不明的服务。

## 三个入口

- 玩家 `/r/CODE`：贡献地点、盲猜、提交与查看个人结果。
- 管理员 `/r/CODE/admin`：邀请、查看准备/提交人数、开始/提前揭晓，也可切换「我的答题」参赛。
- 大屏 `/r/CODE/screen`：展示房间号、实时进度及最终排行榜。

结算页展示排名落印、最准一针和下一次挑战提示；动效仅首次短暂播放，支持减少动态效果。“再开一局”直接创建新房并保留昵称，原房间成绩仍可查看，朋友需使用新房间号加入。

首页可创建或加入房间；直接打开邀请链接时先填写昵称。手机以地图与底部任务面板为主，桌面保留侧栏；「游戏指引」随时可重看。

## 规则

1. 每人搜索并添加两个北京地点才算就绪；至少一人就绪可开局。未就绪和中途加入者旁观本局。
2. 每人三题，至少一道系统题，不含本人贡献，也不重复地点。只有一人就绪时全部抽系统题。
3. 地图点击先预览，确认位置后保存。三题齐全后提交，提交前可改点或撤销。
4. 全员提交自动揭晓，房主也可提前结束。逐题直线距离取整到米，按总误差升序排名；未提交者不计分。
5. 揭晓前没有真坐标、误差或排行榜；大屏只展示已提交者的猜测点。揭晓后展示真实位置与误差连线。

当前为可信局域网应用，无账户认证。房间和进度保存在单进程内存，重启即丢失；同名同角色用于重连恢复，也会接管旧连接。不要将当前管理员链接当作鉴权机制或直接部署公网。
